# 문제 해결

## HTTP 포트를 열 수 없음

홈 화면에 `HTTP 8080 포트를 열 수 없음`처럼 표시되면 앱이 그 포트로 HTTP 서버를 열지 못한 것입니다. 숫자는 설정한 포트입니다. 다른 프로그램이 이미 그 포트를 쓰고 있는 경우가 가장 흔합니다.

1. 설정의 `소스` 탭에서 `HTTP 서버 포트`를 다른 값으로 바꿉니다. 서버가 새 포트로 다시 열립니다.
2. 심박수를 보내는 쪽의 주소도 같은 포트로 바꿉니다.

어떤 프로그램이 포트를 쓰는지 확인하려면 명령 프롬프트에서 다음을 실행합니다.

```text
netstat -ano | findstr :8080
```

앱을 두 개 띄운 경우에도 같은 메시지가 나타납니다. 이미 실행 중인 앱을 먼저 닫으세요.

## 연결 안 됨

홈 화면 오른쪽 위가 `연결 안 됨`이면 심박수가 들어오지 않는 것입니다. 소스에 따라 확인할 곳이 다릅니다.

### Pulsoid

- `Pulsoid 토큰이 설정되지 않음`: 저장된 토큰이 없습니다. `Pulsoid로 로그인`을 누르거나 `액세스 토큰`을 입력하세요. 방법은 [Pulsoid](./heart-rate-source.md#pulsoid)를 보세요.
- `Pulsoid 토큰이 거부됨. 새 토큰을 발급하세요`: Pulsoid가 토큰을 받아들이지 않았거나, 토큰에 심박수 읽기 권한(`data:heart_rate:read`)이 없습니다. `Pulsoid로 로그인`으로 새 토큰을 받거나, 권한이 있는 토큰을 다시 입력하세요. 앱은 이 경우 자동으로 다시 시도하지 않습니다. 새 토큰을 저장하면 바로 다시 연결합니다.
- `WebSocket URL을 가져오지 못함`: 토큰 확인이나 실시간 연결 준비에 실패했습니다. 네트워크 연결을 확인하세요. 앱이 1초부터 30초까지 간격을 늘려 가며 다시 시도합니다.
- 심박수를 Pulsoid로 보내고 있는지 확인하세요. `연결 제한 시간` 동안 데이터가 없으면 연결 끊김으로 처리합니다. 홈 화면의 `다시 연결` 버튼으로 바로 다시 접속할 수 있습니다.

### Pulsoid (Legacy) / Stromno

- `위젯 ID가 설정되지 않음`: 위젯 ID를 입력하지 않았습니다. [위젯 ID를 입력](./heart-rate-source.md#pulsoid-legacy--stromno-위젯-id)하세요.
- `WebSocket URL을 가져오지 못함`: 위젯 ID로 연결 주소를 받지 못했습니다. 위젯 ID가 선택한 소스의 것인지, 오타가 없는지 확인하세요. 네트워크 연결이 끊겼을 때도 나타나며, 앱이 1초부터 30초까지 간격을 늘려 가며 다시 시도합니다.
- 심박수 기기나 Pulsoid, Stromno 쪽에서 데이터를 보내고 있는지 확인하세요. `연결 제한 시간` 동안 데이터가 없으면 연결 끊김으로 처리합니다.
- 홈 화면의 `다시 연결` 버튼으로 바로 다시 접속할 수 있습니다.

### HTTP

- 서버가 열려 있는지 브라우저에서 `http://127.0.0.1:8080/`을 열어 확인합니다. `hr-osc http server`가 보이면 서버는 정상입니다. 포트를 바꿨다면 그 포트로 확인하세요.
- 보내는 쪽에서 `curl -X POST -d 72 http://127.0.0.1:8080/`처럼 `/` 경로로 POST하는지 확인합니다. `400`, `422` 응답이면 [응답 표](./heart-rate-source.md#http)를 보세요.
- 다른 기기에서 보낸다면 `LAN에서 받기`를 켜고 이 PC의 LAN 주소로 보내야 합니다.
- `연결 제한 시간`(기본 10초)보다 드물게 보내면 그 사이에 `연결 안 됨`으로 바뀝니다. 더 자주 보내거나 제한 시간을 늘리세요.
- 홈 화면의 `서버 재시작` 버튼으로 서버를 다시 열 수 있습니다.

## Pulsoid 로그인 실패

`Pulsoid로 로그인` 아래에 빨간 글씨로 나타나는 메시지입니다. 모두 버튼을 다시 눌러 처음부터 시도하면 됩니다.

- `접근이 거부됨`: 브라우저의 승인 페이지에서 접근을 허용하지 않았거나 Pulsoid가 요청을 거절했습니다. 다시 로그인하고 허용하세요.
- `로그인 시간이 지났습니다. 다시 시도하세요`: Pulsoid가 정한 시간(현재 15분) 안에 승인하지 않았습니다. 다시 로그인하고 바로 승인하세요.
- `로그인하지 못했습니다. 다시 시도하세요`: Pulsoid에 연결하지 못했거나 예상하지 못한 응답을 받았습니다. 네트워크 연결을 확인하고 다시 시도하세요. 계속되면 Pulsoid에서 토큰을 직접 발급해 `액세스 토큰` 칸에 붙여넣으세요.

`액세스 토큰` 칸 아래에 `저장하지 못했습니다` 같은 저장 오류가 나타나면 Windows 자격 증명 관리자에 토큰을 저장하거나 읽지 못한 것입니다. 오류 문구는 앱 언어 설정에 따릅니다.

## 아바타에서 값이 0으로 보임

앱 홈 화면에는 심박수가 나오는데 VRChat에서 값이 `0`이거나 움직이지 않을 때 확인할 것입니다.

- VRChat의 Action Menu → Options → OSC가 `Enabled`인지 확인합니다.
- 앱의 `OSC` 탭 호스트와 포트가 VRChat이 받는 주소(기본 `127.0.0.1:9000`)와 같은지 확인합니다.
- 아바타의 Expression Parameters와 애니메이터에 `hr_connected`(Bool), `hr_percent`(Float)가 같은 이름과 타입으로 있는지 확인합니다. 앱의 `파라미터` 탭에서 이름을 바꿨다면 바꾼 이름과 맞아야 합니다.
- 파라미터를 추가하거나 고친 뒤에는 [OSC 설정을 초기화](./vrchat-avatar.md#osc-설정-초기화)하고 아바타를 다시 불러옵니다.
- 앱이 보내는 값은 `심박수 ÷ 최대 심박수`입니다. 심박수가 0이거나 `최대 심박수`가 너무 크면 `hr_percent`가 0에 가깝게 나옵니다. 홈 화면의 퍼센트와 비교해 보세요.
- 연결이 끊기면 앱은 `hr_connected`만 `false`로 보내고 `hr_percent`는 보내지 않습니다.

## OSC 전송 실패

홈 화면 아래쪽에 `OSC 전송 실패`와 주소가 빨갛게 표시되고 `OSC` 탭의 호스트 칸에 `이 호스트로 보낼 수 없습니다`가 나타나면 앱이 그 주소로 OSC를 보내지 못한 것입니다.

- 호스트에 오타가 없는지 확인합니다. 같은 PC의 VRChat이라면 기본값 `127.0.0.1`을 씁니다.
- 다른 PC의 VRChat으로 보낸다면 그 PC의 IP 주소나 호스트 이름을 입력하고, 그 PC의 VRChat이 OSC를 받을 수 있는 상태인지 확인합니다.
- 주소를 올바르게 고치면 다음 전송부터 표시가 사라집니다.
