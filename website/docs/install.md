# 설치와 업데이트

## 설치

1. [최신 릴리스 페이지](https://github.com/kamyu1537/hr-osc/releases/latest)의 **Assets**에서 Windows용 `hr-osc.exe`를 받습니다.
2. 받은 파일을 원하는 폴더에 두고 실행합니다. 별도 설치 과정은 없습니다.

설정 파일은 앱을 처음 실행할 때 자동으로 만들어집니다.

## 처음 설정하기

1. [심박수 소스](./heart-rate-source.md)를 고르고 위젯 ID를 입력하거나 HTTP로 심박수를 보냅니다.
2. VRChat에서 OSC를 켜고 [아바타에 파라미터를 추가](./vrchat-avatar.md)합니다.
3. 홈 화면의 상태가 `연결됨`으로 바뀌고 심박수가 표시되는지 확인합니다.

![HTTP 소스로 84 bpm을 받고 있는 홈 화면](/img/screens/home-connected.png)

## 업데이트

앱은 실행할 때 GitHub의 최신 릴리스를 확인합니다. 현재 버전보다 새 버전이 있으면 화면 위쪽에 `새 버전 … 출시` 알림과 `다운로드` 버튼이 나타납니다. 버튼을 누르면 최신 릴리스 페이지가 열립니다.

앱이 스스로 교체되지는 않습니다. 새 `hr-osc.exe`를 받아 기존 파일을 바꿔 넣으세요. 설정은 앱과 별도 위치에 저장되므로 파일을 바꿔도 유지됩니다. 설정 파일 위치는 [설정 항목 레퍼런스](./settings-reference.md#설정-파일)에 있습니다.

알림은 `×` 버튼으로 닫을 수 있으며, 다음 실행 때 다시 확인합니다.
