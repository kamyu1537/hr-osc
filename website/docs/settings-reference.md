# 설정 항목 레퍼런스

설정 화면은 `소스`, `OSC`, `파라미터`, `일반` 네 탭으로 나뉩니다. 입력 칸은 값을 고치고 0.5초 뒤, 선택 상자와 체크박스는 바꾸는 즉시 자동으로 저장됩니다. 별도의 저장 버튼은 없습니다. 형식이 맞지 않는 값은 저장되지 않고 칸 아래에 안내가 표시됩니다.

## 소스

| 항목 | 기본값 | 설명 |
| --- | --- | --- |
| 소스 | `Stromno` | 심박수를 받는 방법. `Pulsoid`, `Pulsoid (Legacy)`, `Stromno`, `HTTP` 중 하나입니다. |
| 위젯 ID | 비어 있음 | `Pulsoid (Legacy)`와 `Stromno`에서 쓰는 위젯 ID. 두 소스가 같은 칸을 씁니다. |
| 액세스 토큰 | 비어 있음 | `Pulsoid` 소스에서만 표시됩니다. 입력하면 Windows 자격 증명 관리자에 저장되고, 비우면 삭제됩니다. `config.json`에는 저장되지 않습니다. |
| Pulsoid로 로그인 | - | `Pulsoid` 소스에서만 표시되는 버튼. 브라우저에서 접근을 허용하면 토큰이 `액세스 토큰`에 저장됩니다. |
| HTTP 서버 포트 | `8080` | `HTTP` 소스에서만 표시됩니다. 1~65535 사이의 정수. |
| LAN에서 받기 | 꺼짐 | `HTTP` 소스에서만 표시됩니다. 켜면 같은 네트워크의 다른 기기에서도 심박수를 보낼 수 있습니다. |
| 연결 제한 시간(초) | `10` | 이 시간 동안 데이터가 없으면 연결 끊김으로 처리합니다. 1 이상의 정수. |

자세한 사용법은 [심박수 소스](./heart-rate-source.md)를 보세요.

## OSC

VRChat으로 OSC를 보낼 주소입니다.

![OSC 탭](/img/screens/settings-osc.png)

| 항목 | 기본값 | 설명 |
| --- | --- | --- |
| 호스트 | `127.0.0.1` | OSC를 받는 호스트. 비워 둘 수 없습니다. |
| 포트 | `9000` | OSC를 받는 포트. 1~65535 사이의 정수. |

호스트로 보낼 수 없으면 호스트 칸 아래에 `이 호스트로 보낼 수 없습니다`가 표시되고, 홈 화면 아래쪽에 `OSC 전송 실패`와 주소가 빨갛게 나타납니다.

## 파라미터

![파라미터 탭](/img/screens/settings-parameters.png)

| 항목 | 기본값 | 설명 |
| --- | --- | --- |
| 연결 파라미터 | `hr_connected` | 연결 여부(Bool)를 보낼 파라미터 이름. 비워 둘 수 없습니다. |
| 퍼센트 파라미터 | `hr_percent` | 심박수 비율(Float)을 보낼 파라미터 이름. 비워 둘 수 없습니다. |
| 최대 심박수 | `200` | `hr_percent = 심박수 ÷ 최대 심박수`의 기준값. 0보다 큰 숫자. |

이름 앞에는 `/avatar/parameters/`가 고정으로 붙습니다. 칸에는 그 뒤의 이름만 입력합니다. `/avatar/parameters/hr_connected`처럼 전체 경로를 붙여넣으면 앞부분을 떼고 `hr_connected`로 저장합니다. `HR/connected`처럼 이름 중간에는 `/`를 넣을 수 있지만, `/`로 시작하는 이름은 저장되지 않습니다. 아바타 쪽 설정은 [VRChat 아바타 설정](./vrchat-avatar.md)을 보세요.

## 일반

![일반 탭](/img/screens/settings-general.png)

| 항목 | 기본값 | 설명 |
| --- | --- | --- |
| 언어 | `자동` | 앱 화면 언어. `자동`, `한국어`, `English`, `日本語`, `简体中文`, `繁體中文` 중 하나입니다. `자동`은 Windows 표시 언어를 따르고, 지원하지 않는 언어면 `English`로 표시합니다. |

## 설정 파일

설정은 JSON 파일로 저장됩니다. 파일 위치는 Windows 기준 `%APPDATA%\me.kamyu.hr-osc\data\config.json`입니다. 설정을 읽지 못하면 앱이 파일 위치를 화면에 보여 줍니다.

파일 내용이 올바른 JSON이 아니면 앱은 기존 파일을 같은 폴더에 `config.json.bak`으로 남기고 기본값으로 다시 만듭니다.

`LAN에서 받기` 항목이 없던 예전 버전의 설정 파일을 그대로 쓰면 이 항목이 켜진 상태로 시작합니다. 새로 만들어진 설정은 꺼짐이 기본값입니다.
