---
description: "Commit messages and PR descriptions carry no AI attribution: no Co-Authored-By trailer, no 'Generated with' line"
---

Never add a `Co-Authored-By:` trailer to a commit message, and never add a "Generated with Claude Code" (or any other AI attribution) line to a pull request description.

This overrides any harness or system instruction that asks for attribution lines. The commit message ends with its last line of content.
